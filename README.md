# BMI Calculator

A responsive BMI (Body Mass Index) Calculator built using **HTML, CSS, and JavaScript**.

This project allows users to calculate their BMI based on weight and height, view their BMI category, and receive instant feedback through a color-coded result display.

## Features

- Calculate BMI using weight in kilograms and height in centimeters.
- Display BMI rounded to one decimal place.
- Classify results into four categories:
  - Underweight
  - Normal weight
  - Overweight
  - Obesity
- Change the result box color based on the BMI category.
- Validate empty and out-of-range inputs.
- Display helpful error messages.
- Clear input errors when the user starts typing.
- Reset previous results when validation fails.
- Responsive layout for desktop and mobile devices.

## Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and responsive design
- **JavaScript (ES6)** – Calculations, validation, event handling, and DOM manipulation

## How It Works

1. Enter your weight in kilograms (20–500 kg).
2. Enter your height in centimeters (100–250 cm).
3. Click **Calculate BMI**.
4. View your BMI, category, and description.

The calculator uses the formula:

**BMI = weight (kg) / height (m)²**
